# dev-card

Простая страница-визитка разработчика, созданная в рамках практической работы по основам Git (Хекслет Колледж, курс «Основы алгоритмизации и программирования», 09.02.13).

## Стек

- HTML5
- CSS3
- Git / GitHub (SSH, ветвление, Conventional Commits)

## Структура проекта

- `index.html` — разметка страницы-визитки
- `style.css` — базовое оформление карточки
- `.gitignore` — исключение временных файлов и секретов
